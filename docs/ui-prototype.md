## 5. 设计要点

### 5.1 色彩系统
```
背景色:    #0F172A (深蓝黑)
卡片背景:  #1E293B (深灰)
边框:      #334155
主文字:    #F8FAFC (白)
次文字:    #94A3B8 (灰)

涨/盈:     #22C55E (柔和绿)
跌/亏:     #EF4444 (柔和红)
主按钮:    #3B82F6 (蓝)
```

### 5.2 交互状态
```
按钮悬停:   scale(1.02) + 亮度提升
按钮按下:   scale(0.98)
行情更新:   数字闪烁 300ms
加载中:     旋转图标 + 禁用按钮
```

### 5.3 响应式断点
```
移动端:  < 768px     - 单列布局，底部导航
平板端:  768px-1024px - 双列布局
桌面端:  > 1024px    - 三栏布局，侧边导航
```
